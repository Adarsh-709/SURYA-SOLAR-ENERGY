# ☀️ Surya Solar Energy

> **Clean Energy For a Brighter Tomorrow**

Surya Solar Energy is a premium, high-conversion landing page built for a leading solar energy provider covering North Bengal and Sikkim. It features a modern, futuristic UI with smooth micro-animations, glassmorphism design, and an integrated WhatsApp lead generation system.

## 🚀 Features

- **Modern & Premium UI:** Crafted with a dark-mode theme featuring neon-yellow accents for maximum visual impact.
- **WhatsApp Integration:** "Get a Free Quote" and "Careers" forms are directly wired to output properly formatted messages straight into the business WhatsApp account.
- **Dedicated Careers Portal:** Custom role-based application tabs for Distributors, Commission Agents, and On-Field Marketers.
- **PM Surya Ghar Yojana Support:** Integrated informative sections that guide users on how to obtain 100% subsidy assistance.
- **Fully Responsive Layout:** Flawless rendering on both desktop and mobile devices.
- **Fast & Optimized:** Built entirely using React and Vite with a heavily optimized asset footprint for extremely fast load times.

## 🛠️ Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **Icons:** Lucide React
- **Styling:** Custom Vanilla CSS with CSS Variables and Animations

## 💻 Running Locally

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure you have Node.js installed on your system.

### Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/Adarsh-709/SURYA-SOLAR-ENERGY.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd SURYA-SOLAR-ENERGY
   ```
3. **Install NPM packages:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
